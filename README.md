# pitanga-bank
>Pitanga Bank is a fictional digital bank API built with Java and Spring Boot. It is a simulation project for my portfolio, not a commercial product or real work experience.

## About
Pitanga Bank is simulate app of real bank promising:
 - Clients and authenticator: Register,login,profiles of client and operator.
 - Accounts: Opening of accounts, balance inquiry, block and End.
 - Transference: between internals accounts and simulate PIX.
 - Statement: page list with filter by period and type.
 - limit and Anti-fraud: Limit of diary transference and rules of block.
 - Registry: Detailed register of who did what and when.
